# Brand: Nexa IT Solution

Pulled from the landing page in this repo (`src/`). Edit freely. Every video skill reads this.

## Colour
| token | hex | use |
|-------|-----|-----|
| primary | `#195CEA` | caption highlight, accents, lower-third bars |
| primary-alt | `#2761E3` / `#2560E5` | gradients with primary |
| ink | `#000000` | backgrounds for title cards, text outline |
| paper | `#FFFFFF` | caption text, light cards |

Never put primary-blue text on a busy blue background; use white text with a blue bar instead.

## Type
- Display / captions: Inter (bold/extra-bold). Fallback: any geometric sans installed on the machine.
- Body / lower thirds: Inter regular/medium.

## Logo
- `public/logo.png`. Use it on end cards and as a small corner bug (top-left, 6% of width, 80% opacity) only when asked.

## Voice & pacing
- Confident, clear, tech-forward, never hype-y.
- Default max pause: 0.45 s for shorts, 0.6 s for long-form.
- Keep the speaker's natural breaths at sentence ends; never cut mid-word.

## Do not
- Change the speaker's voice, face or words.
- Add stock "corporate" whooshes on every cut.
- Cover the speaker's face with graphics.
