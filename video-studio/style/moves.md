# Editing moves (style guide)

The repeatable "moves" that make our edits look like ours. Built by the `video-style-guide`
skill from reference videos, then refined by feedback. Each move: when it fires, what it does,
numbers.

| # | move | trigger | spec |
|---|------|---------|------|
| 1 | Hook cold-open | first 2 s | open on the strongest line in the transcript, no logo, no intro |
| 2 | Punch-in | emphasis word / new point | scale 1.0→1.12 over 0 frames (hard cut), back out on next sentence |
| 3 | Keyword pop | numbers, product names | bold-pop caption word in `primary` (brand.md), 108% scale |
| 4 | Lower third | first time a person/product is named | 3 s, slide-in 200 ms, blue bar + white text, bottom-left inside title-safe |
| 5 | End card | last 3 s | logo + one CTA line, ink background |
